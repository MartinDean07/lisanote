**Lisanote 2.0** — record the sound, transcribe audio files, and a clearer options panel.
📖 **[Read what's new in 2.0](https://github.com/MartinDean07/lisanote/blob/main/docs/WHATS-NEW.md)**

### Highlights
- 🔴 **Record the sound** — tick **Record** to save the session as one `.m4a` with separate tracks (mixed · what I hear · my mic). Off by default; red **● REC** badge and a reminder to tell participants. Record-only mode needs no API key.
- 📂 **Transcribe audio files** — upload or drag & drop phone voice memos and other audio/video files (m4a, mp3, wav, ogg, amr, mp4…). Timestamps follow the recording.
- 🧭 **Clearer options** — labelled rows with icons: *Listen to*, *Save* (Transcript / Record), *Language*.

### Downloads
| System | File | Install |
|---|---|---|
| 🐧 **Linux** (Ubuntu, Debian, Mint…) | `lisanote_2.0.0_all.deb` | Double-click, or `sudo apt install ./lisanote_2.0.0_all.deb` |
| 🍎 **macOS** (Apple Silicon) | `Lisanote-2.0.0-macos-arm64.dmg` | Drag to Applications; first start: right-click → **Open** (not notarized) |
| 🪟 **Windows 10/11** (experimental) | `Lisanote-2.0.0-windows-setup.exe` | If SmartScreen warns: **More info → Run anyway**. Recording isn't available on Windows yet. |

On first start, open **Settings** and paste your OpenAI / Groq / Mistral key (or a custom endpoint). Verify downloads with `SHA256SUMS.txt`.
